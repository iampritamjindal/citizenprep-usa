CitizenPrep USA — MVP
========================

Open index.html in a modern browser.

Included:
- Responsive homepage
- 20-question randomized practice test
- 12/20 practice pass threshold
- Results and answer review
- Study mode
- No backend required

Important:
This is an independent practice tool, not a USCIS website.
The current USCIS 2025 civics test has 128 questions. This MVP seeds 31 official-question items so the product can be tested immediately; the next build should import and validate the complete 128-question bank and maintain changeable answers separately.

Official source:
https://www.uscis.gov/sites/default/files/document/questions-and-answers/2025-Civics-Test-128-Questions-and-Answers.pdf
